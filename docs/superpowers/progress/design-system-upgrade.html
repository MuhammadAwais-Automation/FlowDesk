What research settled

Four decisions made before any code, each with the reason it went that way.

Decided

Fonts ship in the app, not from a CDN

The poster generated during testing pulled Anton from Google's CDN — so it renders differently offline and the export silently loses the face. Fontsource packages, latin subset, ~15–25 MB for 100 families. The project already used this pattern for three fonts.

Decided

Seven text effects are one vocabulary

Canva's Shadow, Lift, Hollow, Splice, Echo, Neon and Glitch all decompose into text-shadow and -webkit-text-stroke. So they are one parameterised primitive set, not seven implementations — which is what keeps them editable after the fact.

Decided

Photoshop's layer model fits the DOM

Reorder is sibling order, group is a wrapper, hide is display, opacity and blend are CSS. Two things do not map — fill-versus-layer opacity, and clipping masks — and are deliberately out of scope rather than faked.

Load-bearing

OpenType features are not optional

The reference posters' swash is a separate glyph inside the font file. No amount of CSS produces it. Without a font-feature-settings control, that look stays permanently out of reach.

Three agent-native features

Each is pointless without an agent, which is why no manual tool has them.

Task 11

Design Lint

The guide made the rules readable; lint makes them enforced. The poster built during testing used one typeface and a texture at opacity: 0.16 — the exact number the guide warns about — because advice a model reads is advice it can ignore. Each violation carries a one-click agent fix.

Task 12

Variant fan-out

One command, N genuinely different design directions side by side — not N renders of one layout. A person cannot do this because their cost per variant is an hour. The agent's is one call.

Task 13

Design memory

Every edit made right after the agent acts is a correction. Three of the same shape becomes a stated preference folded into the guide — so it stops being static advice and becomes the record of this user's taste, learned from what they change rather than what they say.
