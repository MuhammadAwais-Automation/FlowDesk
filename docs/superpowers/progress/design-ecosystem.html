Confirmed hazard

The 16-context ceiling is real — and silent

24 contexts were requested. Every single request succeeded: nothing returned null, nothing threw. Only 16 were still alive afterwards. Eight died without a word.

Per-artboard contexts would have shipped as blank artboards with no error. One carousel is 8 artboards.

Still open

Assumption, not fact. Each paired with the experiment that would settle it.

QuestionStandingCheapest experiment
Does quantised ISNet keep hair and feather edges? Open One photo through fp32, fp16 and quint8, compared at 100%. fp32 is now proven to run at 2.6s — the question is only how much smaller we can go
Is 2.6s fast enough to feel interactive? New Published figures said ~350ms; this GPU is an older AMD GCN-5 and fp32 is the heaviest tier. Try fp16 before designing a progress affordance around it

Blocked on you

One thing, and the loop cannot start without it.

Waiting

The reference posters need to be files on disk

The critic that judges each round has to open the real image. Given only a written description it invents the comparison and approves everything — that is the single most common way this kind of loop fails, and it fails invisibly.

Save the reference set into E:\FlowDesk\docs\superpowers\references\. Names that tell them apart are enough: millenium-parrot.png, fonts-diet-coke.png, mango-productivity.png.

They were shared in the conversation, which is why the system has already been read out of them — see specs/2026-09-02-reference-system.md, where slides 2–7 turned out to be one template run six times. That reading is written down and usable. But a fresh critic cannot see a conversation, only the disk.

Everything above ran without them. Everything that gets judged needs them.

Evidence lives in the repo — probes/out/spike-runtime-gpu.json for the numbers above, docs/superpowers/specs/ for the research they came from.
