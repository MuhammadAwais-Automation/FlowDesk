# References

Drop the reference images here — the ones the design work is judged against.

This folder is the **bar**. A critic that cannot open the real image will
invent the comparison and approve everything, which is the single most common
way this kind of loop fails. So the rule is simple: if it is not in this
folder, it is not a bar.

Name files so a fresh agent can tell them apart without asking:
`poster-millenium-parrot.png`, `cover-halftone-01.png`, and so on.
