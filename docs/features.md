# Features

FlowDesk is a local-first AI creator workstation.

## AI Browser

- Open AI tools such as ChatGPT, Claude, Gemini, Grok, and custom URLs.
- Pair each AI tool with a Gmail session.
- Keep each account isolated with a persistent Electron partition.
- Use native browser controls and session clearing.

## Prompt Injection

- Select a saved prompt.
- Fill `{{variables}}` when needed.
- Inject into supported AI tool inputs.
- Track local prompt usage.

## Prompt Library

- Save local prompts.
- Organize prompts by category.
- Search prompt names and contents.
- Highlight variables.

## Workspace Prompt Metadata

- Create local workspaces.
- Store workspace-aware prompt rows, folders, version history, tags, favorites,
  usage count, and last-used timestamps.

## Gmail Accounts

- Add multiple Gmail accounts through isolated login windows.
- Rename accounts.
- Set tab colors.
- Open Gmail inboxes inside the app.

## YouTube Studio

- Add multiple YouTube/Google accounts.
- Switch between isolated Studio sessions.
- Rename, remove, reload, re-authenticate, or open externally.

## Social Hub

- Open social platforms from a right-side dock.
- Keep platform sessions persistent.
- Use back, forward, and reload controls.

## Personal Workspace

- Connect one Google account for Calendar and Tasks.
- Use a dedicated isolated session.
- Logout clears the local session.

## Settings

- Launch on startup.
- Minimize to tray.
- Configure global shortcuts.
- Manage local workspaces.
